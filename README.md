# AI-Assisted Student Record and Result Management System

## About the Project

This is a menu-driven Student Record and Result Management
System developed using C programming.

The program is used to store and manage student academic
records.

## Features

- Add student details
- Search student by SAP ID
- Display all student records
- Delete student record
- Calculate CGPA
- Calculate year-wise average CGPA
- Sort students by SAP ID
- Sort students by name
- AI-Assisted Academic Advisor

## Student Information Stored

The program stores:

- SAP ID
- Roll Number
- Name
- Phone Number
- Email ID
- Year
- Semester
- SGPA of available semesters

## CGPA Calculation

CGPA is calculated by taking the average of the available
SGPA values of a student.

## AI-Assisted Academic Advisor

The program provides academic advice based on the
student's CGPA using if-else statements.

The categories are:

- Excellent Performance
- Good Performance
- Needs Improvement
- Requires Immediate Attention

## Technology Used

- C Programming Language
- Visual Studio Code
- Git
- GitHub
- ChatGPT as an AI learning assistant

## How to Compile

Open the terminal and use:

gcc SAP_ID.c -o student

Replace SAP_ID with your actual SAP ID.

## How to Run

On Windows:

student.exe
